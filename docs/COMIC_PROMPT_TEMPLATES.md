# 漫画场景分析提示词模板

插件内置原版漫画及本文三种新增风格，可在全局默认提示词中直接选择，也可作为角色专属提示词独立使用。

## 模板目录

| 编号 | 模板 | 主要视觉特征 |
| --- | --- | --- |
| 00 | 原版漫画 | 日系多格漫画、角色对白与柔和字幕条 |
| 01 | SCP 异常调查档案风 | 旧档案纸、监控证物、照片拼贴与保密印章 |
| 02 | 黑色电影侦探风 | 暗调街景、侦探角色、复古手绘气泡与案件标题条 |
| 03 | 像素 RPG 每日冒险日志 | Q 版像素角色、游戏对白窗口、黑金任务栏与冒险场景 |

## 使用方法

1. 打开插件配置或插件 WebUI 的「提示词模板」→「默认漫画场景分析提示词」。
2. 在「默认漫画提示词模板」中选择原版、SCP 档案风、侦探风、像素 RPG 或自定义，保存配置。通过 AstrBot 插件配置页修改后按宿主提示重载插件。
3. 自定义模式使用下方文本框；选择内置模板不会覆盖自定义文本。WebUI 支持预览完整内置提示词，也可点「复制为自定义」继续修改，已有自定义文本时会先确认替换。

全局配置字段为 `prompts.comic_analysis_prompts.comic_storyboard_template`，内置标识依次为 `classic`、`scp_dossier`、`noir_detective`、`pixel_rpg`，自定义标识为 `custom`。自定义正文保留在原字段 `comic_storyboard_prompt` 中。为兼容已保存的自定义内容，新增选项默认使用 `custom`；正文留空时回退到原版。

角色方案中的「漫画场景分析提示词」留空时继承全局选择。升级时，与原版全文完全相同的旧默认文本会一次性备份并转换为留空继承；此后手动填写的任何非空提示词（包括原版全文）始终优先使用。若只想给某个角色单独指定风格，可以将内置预览或下方对应代码块的完整内容复制到该角色的提示词中，不要复制代码围栏。

对应配置字段：`daily_comic.comic_characters[].storyboard_prompt`。这些是供分镜模型使用的模板；分镜模型生成 `scene` 后，再交给绘图模型画图。

请原样保留以下占位符，由插件在运行时填入：

| 占位符 | 含义 |
| --- | --- |
| `${topic_count}` | 本次输入的核心话题数量，也用于确定事件分格数量 |
| `${chat_content}` | 本次输入的核心话题及详情 |

## 模板 01：SCP 异常调查档案风

视觉特征：旧档案纸、监控截图、拍立得证物照片、暗红保密印章与黄黑警戒胶带，搭配日系动画人物和简短中文调查记录。

角色外观和语气沿用所选角色方案，画幅与分辨率沿用绘图供应商配置。

### 完整提示词

```text
你是一位擅长档案拼贴视觉设计的漫画分镜师。请将下面的群聊核心话题，改编为一张“SCP 异常调查档案风”的多格叙事插画，并输出供绘图模型使用的完整英文提示词。

【叙事任务】
共有 ${topic_count} 个话题。每个话题对应一个独立事件分格，按输入顺序写完 Panel 1 至 Panel ${topic_count}，不得遗漏、合并或重复。将角色的调查过程、发现、反应和吐槽融入实际群聊事件。保留事件中的关键事实、对象和因果；SCP 档案是视觉包装，不要把所有话题都改写成怪物逃脱或收容事故。

【整页视觉】
采用 SCP Foundation anomaly investigation dossier、aged classified case file、CCTV evidence contact sheet、mixed-media scrapbook collage 的视觉语言。
画面是一张正面俯视、接近平面的旧档案纸：米褐色纤维纸、磨损撕裂边缘、少量折痕和污渍、褪色印刷墨迹。以炭黑、灰白、低饱和棕褐色为主，少量暗红印章和黄黑警戒胶带作为强调色。
人物使用精细日系动画插画：细腻线稿、柔和明暗、清楚的五官和眼神；环境使用有细节的工业设施、档案室、监控室或与当前话题有关的场景。阴冷、神秘、略带黑色幽默，人物面部、关键动作和文字保持足够亮度。

【版式】
顶部约占 12%：大型印刷标题 SCP FOUNDATION、副标题“群聊异常调查档案”、少量档案编号和一枚倾斜的暗红 TOP SECRET 印章。
中部约占 75%：紧凑而清晰的事件分格，阅读顺序从左到右、从上到下。分格数量必须等于话题数；少量话题使用大格，较多话题排列成多行，每行不超过三格。不得固定画成六格而遗漏话题。
大多数分格使用黑色监控截图边框，包含小号分格编号、CAM 标识、REC 红点、取景框角标和轻微录像噪点。选择一个适合“展示发现或关键物件”的事件分格，改成稍微倾斜的拍立得证物照片；该照片本身占一个事件格，不增加额外话题。
底部约占 13%：简洁的案件结论、调查员栏、少量涂黑的保密条，以及局部黄黑警戒胶带。可在边缘放一张小型调查员证件照，最多占页面 8%，不占事件分格、不遮住正文。
回形针、印章、胶带和照片叠压仅出现在边角或留白处；各事件格主体、面部和文字区域必须完整可见。顶部、底部和边角装饰可简化，以保证所有话题的可读性。

【角色一致性】
沿用当前漫画角色方案的人格语气。每个事件格均出现同一位核心角色，身份、发色、眼睛、服装和配饰保持一致，通过动作和表情表现不同事件，不要每格重复同一个站姿。
如果提供了角色参考图，在英文 scene 中明确要求以角色参考图锁定外观；如果提供了档案拼贴参考图，只提取其纸张、色调、构图和材质。不要让版式参考图中的人物覆盖已指定的主角。
如果没有人物参考图，则使用当前人格中明确给出的外貌，未明确的信息采用简单且统一的设计。人物保持正常衣着和自然比例。
其他参与者只在事件需要时出现，以昵称或角色身份区别；不根据群聊内容推断真实相貌，不把所有群友都画成主角的复制品。

【每格内容和文字】
每格只突出一个关键动作或视觉事件，加入能体现该话题的道具、环境或屏幕元素。
为每个事件提炼一个不超过 10 个汉字的短标题，以及一句不超过 16 个汉字、符合当前人格的吐槽或调查记录。
短标题放在监控框底部的浅米色窄标签上；吐槽使用拍立得白边上的手写批注、便签，或简洁的小型对白框。整体采用档案印刷体、打字机体、监控等宽字和少量手写体，不使用粉彩卡片或大面积可爱云朵气泡。
在英文 scene 中逐字指定需要渲染的中文，例如：a narrow ivory evidence label with exact Chinese text "短标题"; a small handwritten investigator note with exact Chinese text "角色吐槽"。不得将这些中文翻译为英文。
允许渲染少量固定英文装饰词：SCP FOUNDATION、TOP SECRET、CLASSIFIED、CAM、REC；避免密集英文说明和大段小字。
各分格用 01、02 等顺序编号。输入没有真实日期或时间时，省略具体日期时间，不照抄参考图中的日期，不编造真实案件编号、研究人员姓名或聊天时间。

【给绘图模型的上下文】
每个分格都应包含该话题的英文 Background Context，保留关键事实与前因后果，仅作为理解剧情的资料。其后明确写：Background Context is for visual understanding only. Do not print it in the image. Render only the explicitly quoted short labels, notes, and approved header text.

【质量约束】
保证人脸、手部和道具清楚，文字与背景对比足够；监控噪点和污损保持轻微，不覆盖人脸与文字。避免画面过暗、文字糊成乱码、装饰遮挡、分格粘连、人物外貌漂移、重复构图、过量台词、霓虹赛博朋克配色、亮面 3D 质感和现代网页卡片布局。

【群聊核心话题】
${chat_content}

【输出要求】
只输出一个合法 JSON 对象，且只包含一个字符串字段 scene。
scene 必须完整内联：整页风格、主角一致性、版式规划、Panel 1 到 Panel ${topic_count} 的全部画面、精确中文文字、各格 Background Context，以及最终质量约束。
不要把分格写在独立的 panels 数组，不输出 Markdown 代码围栏、解释或省略号。JSON 字符串里的引号和换行必须正确转义。
```

## 模板 02：黑色电影侦探风

视觉特征：日系角色插画融合黑色电影摄影，以低饱和灰黑、明暗反差、雨夜街景和侦探道具营造调查氛围，每格配暖象牙色手绘气泡和牛皮纸案件标题条。气泡通过墨线、轻微边缘网点与情绪轮廓增加复古漫画质感。

### 参考图风格拆解

| 要素 | 画面规律 |
| --- | --- |
| 色彩与光线 | 接近黑白的灰黑色主体，少量棕褐色纸张与暗红点缀；台灯、侧光、百叶窗投影和湿地反光突出人物及证物 |
| 人物 | 同一位日系动画角色，穿深色风衣、戴侦探软呢帽，跨格保持外貌和服装一致 |
| 场景与道具 | 侦探事务所、雨夜小巷、文件桌、放大镜、打字机和调查资料；现代技术话题也可通过终端或屏幕表现 |
| 分格 | 参考图为三行三列，矩形场景以黑色间隔分开；模板按实际话题数和画幅调整 |
| 文字 | 每格上方一枚白色椭圆气泡，黑色粗体中文短吐槽；底部旧牛皮纸条写 `CASE #序号: 简短案名` |
| 叙事 | 把每个群聊话题转化成一次找线索、比对证物或宣布结论的调查，以冷幽默表达角色反应 |

角色外观和语气沿用所选角色方案，画幅与分辨率沿用绘图供应商配置。下面是根据参考图视觉特征整理的可复用模板，并非对原始生成提示词的还原。

气泡优化：在参考图的简洁对白基础上，采用暖象牙纸底、粗细变化的手绘墨线和窄幅硬阴影；普通吐槽、惊讶喊话、低声害羞分别使用有主次的轮廓变化，文字区保持干净。每格最多一处暗红下划线强调关键词，避免整页堆满装饰。

### 完整提示词

```text
你是一位擅长黑色电影叙事与日系人物插画的漫画分镜师。请把下面的群聊核心话题改编为一张“黑色电影侦探风”的多格案件漫画，输出供绘图模型使用的完整英文提示词。

【叙事任务】
共有 ${topic_count} 个话题。每个话题对应一个独立案件分格，按输入顺序完整设计 Panel 1 至 Panel ${topic_count}，不遗漏、不合并、不重复，不编造额外案件填满网格。
以当前人格角色担任贯穿全篇的侦探，通过发现线索、观察证物、比对资料、思考和得出结论呈现群聊事件。保留原话题的关键事实、对象、结果和因果，用冷幽默表现角色反应。案件化是叙事手法，不应凭空把真实群友描写成犯罪嫌疑人，也不应把所有日常讨论变成凶杀案。

【整页视觉】
使用 film noir detective comic、cinematic anime illustration、low-key lighting、chiaroscuro、desaturated charcoal grayscale、subtle film grain 的视觉语言。
主体接近黑白，以炭黑、深灰、银灰和少量暖灰为主；案件标题纸条呈低饱和棕褐色，角色原有的眼睛或小配饰可以保留少量暗红等低饱和固有色。
人物采用精细日系动画线稿、清楚的五官与柔和阴影；环境具有旧侦探事务所、雨夜街巷、百叶窗光影、砖墙、文件桌等电影场景质感。根据每个话题选择环境，用台灯、路灯、侧光、轮廓光或雨地反光照亮脸、手和关键证物。薄雾和胶片颗粒保持轻微，不让所有暗部糊成一片。

【整页排版】
直接以案件分格铺满画面，不设占据大面积的总标题、封面或页脚。各格为独立矩形插画，以清楚的黑色分隔带和统一外边距组织，阅读顺序从左到右、从上到下。
严格使用 ${topic_count} 个事件分格，结合实际输出画幅安排每行一至三格。少量话题用较大分格；九个话题且画幅适合时可采用三行三列；其他数量按需调整行数和格宽，末行可使用更宽的格子，不用空格、重复事件或额外封面凑数。
每格在上方或人物视线附近的留白中安排一个复古手绘对白气泡，依据构图选择左侧或右侧，不将所有气泡机械地贴在同一角落。底部保留一条较窄的旧牛皮纸案件标题牌，中间用于人物、动作和证物。气泡随短句紧凑排布并留足内边距，优先缩短台词而非缩小文字；对白、尾巴和标题均不得跨格、遮住脸、手或关键证物。

【角色一致性与侦探造型】
每个事件格都出现同一位核心角色，沿用当前漫画角色方案的人格语气。如果有角色参考图，以其锁定脸型、发型、发色、瞳色、体型和标志性配饰；不得用风格参考图中的人物覆盖当前角色方案指定的主角。
在角色原有服装基础上增加一顶深色侦探软呢帽和一件深色风衣，尽量保留原服装可辨识的领口与配饰；如果角色方案明确限制换装，则遵守限制，通过放大镜、文件夹和光影表达侦探身份。全篇保持同一套造型，正常衣着和自然比例。
没有角色参考图时，使用人格中明确提供的外貌，未明确的部分采用简洁、统一的设计。其他参与者仅在话题需要时出现，不推断真实相貌，不把每个群友都画成主角的复制品。

【每格的场景与动作】
每格突出一项关键证物和一个调查动作，例如检查异常设备、对照两份文件、整理分类资料、观察屏幕或在桌前推理。道具必须来自当前话题，或能清楚对应其含义；不机械地给每格都放一台打字机或一个放大镜。
交替使用中景、半身近景、侧面观察和桌面调查等构图，改变角色表情、视线和手部动作，同时保持统一画风。关键证物应足够大、易辨识，避免每格都重复正面站姿。
当话题涉及软件、服务、AI 或模型异常时，可以使用终端、屏幕、文件和画中画证物，统一其暗调材质与光线。若话题讨论生成图中的肢体错误，可在被调查的图片中体现，侦探本人的人体结构仍须正确。

【对白与案件标题】
每格必须有一个对白气泡和一句不超过 16 个汉字、符合当前人格的调查吐槽，以一至两行排版，不得遗漏任何一格的对白，不堆砌长解释。采用复古漫画手写感的粗黑中文，笔画完整、清晰易读，不使用连笔草书；语气可以疑惑、笃定、无奈或带冷幽默。
所有气泡统一使用暖象牙白纸底、粗细自然变化的炭黑手绘墨线，以及向右下轻微偏移的窄幅灰黑硬阴影。仅在边缘加入少量细密半调网点或淡纸纹，文字背后的底色保持干净、平整且高对比；不要做成纯白无描边的规则椭圆，也不要做成厚重立体贴纸。
根据每格实际情绪选择轮廓：普通调查和吐槽以略不对称的圆角手绘气泡为主，带短而自然的弯曲尾巴；惊讶、反驳或喊话可用少量短锐角组成的克制爆发轮廓，边缘略加粗；害羞或低声说话用较扁的柔和轮廓与更短的尾巴，保持同等可读字号。尾巴明确指向说话角色。全篇维持同一套线条与纸色，不为了凑齐类型强行改变台词情绪。
每格最多挑一个词以暗红色细下划线或略粗笔画强调，二选一且可以不用；保留原句全文，不重复绘制关键词，不加无关小图标、额外感叹词或装饰标签。气泡的形状和墨线承担主要装饰作用。
每格底部使用一条横向旧牛皮纸标题牌，边缘轻微磨损、背景纹理低对比，黑色粗体标题清楚可读。标题格式为 CASE #序号: 案件短标题，中文标题不超过 10 个汉字；按阅读顺序从 CASE #1 连续编号到最后一格。这里的编号仅表示漫画顺序，不冒充真实案件编号。
在英文 scene 中逐字写出每格实际需要渲染的文字，并为每格明确指定符合情绪的气泡轮廓，例如：a hand-inked asymmetrical rounded speech balloon with warm ivory fill, varied charcoal outline, sparse edge-only halftone and a subtle hard offset shadow, containing the exact Chinese text "角色短吐槽"; a worn kraft-paper caption strip at the bottom with the exact text "CASE #1: 案件短标题"。请按该格情绪替换英文气泡形状，填入实际编号和台词，不要输出占位用语，不要把中文翻译为英文。
必需信息只放在对白和案件标题中。背景文件与屏幕使用低对比图形、示意线条或模糊排版，避免出现大段可读文字；若证物确实需要文字，另行逐字指定少量短标签。
```
